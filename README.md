# Zelda-Soulsborne Pygame

A 2D top-down action RPG built in Python using **Pygame**. This project was created a couple of years ago following the excellent Zelda-style game tutorial by **Clear Code**, incorporating elements inspired by classic Zelda games and Soulsborne mechanics (like stats, stamina, and magic systems).

## 🎮 Controls

| Action | Key Binding |
| :--- | :--- |
| **Movement** | Arrow Keys (or WASD depending on config) |
| **Weapon Attack** | `Spacebar` |
| **Magic Spell / Heal** | `Left Ctrl` |
| **Cycle Weapons** | `Q` |
| **Cycle Magic** | `E` |
| **Toggle Upgrade Menu** | `M` |

## 🚀 Features

* **Real-time Combat:** Hack-and-slash mechanics with multiple weapon types and magic spells.
* **Enemy AI:** Monsters that track, pathfind, and attack the player.
* **Exp & Leveling:** An in-game upgrade menu to boost player stats (Health, Stamina, Attack, Magic, Speed).
* **Particle & Sound Effects:** Immersive audio and visual feedback for combat and spells.

## 🛠️ Setup Instructions

### Prerequisites
Make sure you have **Python 3.x** and **Pygame** installed. 

### Installation
1. Clone this repository:
   ```bash
   git clone https://github.com
   ```
2. Navigate to the project directory:
   ```bash
   cd YOUR-REPO-NAME
   ```
3. Install dependencies:
   ```bash
   pip install pygame
   ```
4. Run the game:
   ```bash
   python main.py
   ```
